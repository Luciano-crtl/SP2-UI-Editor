# ---- features of the window ----
feat.pick|Escolher no jogo|Liga o modo de escolha. Vá ao jogo, passe o mouse e clique no que quer mudar: ele fica com um contorno azul e aparece à direita. Esc cancela. O clique não aciona o botão do jogo.|Pick in the game|Turns on picking. Go to the game, move the mouse and click what you want to change: it gets a blue outline and shows on the right. Esc cancels. The click does not press the game's button.
feat.undo|Desfazer|Volta a última mudança, como Ctrl+Z. Pode apertar várias vezes. Desfaz também o que o Claude mudou.|Undo|Takes back the last change, like Ctrl+Z. Press it as often as you want. It also takes back what Claude changed.
feat.redo|Refazer|Faz de novo o que você acabou de desfazer (Ctrl+Y).|Redo|Does again what you have just undone (Ctrl+Y).
feat.list|Mudanças|Mostra tudo o que foi mudado nesta sessão, em ordem, e quem mudou (você ou o Claude).|Changes|Shows all that was changed in this session, in order, and by whom (you or Claude).
feat.panels|Painéis|Cria janelas suas dentro do jogo. Uma janela nova começa vazia: você põe nela seções, textos e botões.|Panels|Makes windows of your own inside the game. A new window starts empty: you put sections, texts and buttons in it.
feat.packs|Pacotes|Um pacote é um arquivo que guarda as suas mudanças. Você pode ter vários, ligar e desligar cada um e mandar o arquivo para um amigo.|Packages|A package is a file that keeps your changes. You can have several, switch each on or off, and send the file to a friend.
feat.save|Salvar|Guarda as mudanças no pacote atual. Sem salvar, elas se perdem quando o jogo fecha.|Save|Keeps the changes in the current package. Without saving they are lost when the game closes.
feat.claude|Claude pode editar|Deixa o assistente Claude mudar a interface. Desmarcado, ele só pode olhar e apontar elementos. Desliga sozinho quando o plugin recarrega.|Claude may edit|Lets the Claude assistant change the interface. Unchecked, it can only look and point at elements. Goes off by itself when the plugin reloads.

feat.search|Busca|Escreva uma palavra que aparece no jogo (como BUILD) para achar o elemento que a mostra.|Search|Type a word that shows in the game (such as BUILD) to find the element that shows it.
feat.vis|Só visível|Marcado, a lista mostra só o que está na tela agora. Desmarque para achar coisas escondidas.|Visible only|Checked, the list only shows what is on the screen now. Uncheck it to find hidden things.
feat.reload|Atualizar|Lê de novo a lista de elementos do jogo.|Refresh|Reads the game's list of elements again.
feat.places|Ir para um lugar|Atalho para os lugares mais úteis: menu de voo, barra do designer, propriedades da peça e os seus painéis abertos.|Go to a place|Shortcut to the most useful places: flight menu, designer bar, part properties and your open panels.
feat.tree|Árvore de elementos|A interface é feita de caixas dentro de caixas. Clique na setinha para abrir uma caixa e no nome para escolher. Arraste um item para mudar a ordem. Cinza = escondido. Verde com + = criado por você.|Element tree|The interface is made of boxes inside boxes. Click the little arrow to open a box and the name to pick it. Drag an item to change the order. Gray = hidden. feat.shot|Imagem do jogo|Uma foto do jogo, atualizada o tempo todo. Clique nela para escolher um elemento sem ir até o jogo.|Picture of the game|A picture of the game, refreshed all the time. Click it to pick an element without going to the game.
feat.live|Imagem ao vivo|Desmarque se o jogo ficar lento: a imagem só atualiza quando algo muda.|Live picture|Uncheck it if the game gets slow: the picture is then only refreshed when something changes.
feat.crumbs|Caminho|Mostra dentro de que caixas este elemento está. feat.addInside|Adicionar: Dentro|Põe algo novo dentro deste elemento, no fim. Serve para caixas, listas e painéis.|Add: Inside|Puts something new inside this element, at its end. For boxes, lists and panels.
feat.addAfter|Adicionar: Depois|Põe algo novo logo depois deste elemento, no mesmo lugar.|Add: After|Puts something new right after this element, in the same place.
feat.move|Subir e Descer|Muda a ordem do elemento entre os vizinhos. Só se nota em listas e fileiras.|Up and Down|Changes the element's order among its neighbors. You only notice it in lists and rows.
feat.hide|Esconder ou Remover|O que é do jogo fica só escondido (dá para mostrar de novo). O que você criou é removido.|Hide or Remove|What belongs to the game is only hidden (it can be shown again). What you made is removed.
feat.basic|Básico|As propriedades mais usadas. Mude um valor e aperte Enter ou clique fora: o jogo muda na hora. Nome em amarelo = você já mudou.|Basic|The properties used most. Change a value and press Enter or click elsewhere: the game changes at once. Yellow name = you changed it.
feat.adv|Avançado|Todas as outras propriedades. Não é preciso mexer aqui para o uso comum; o Desfazer conserta qualquer engano.|Advanced|All other properties. No need to touch these for common use; Undo fixes any mistake.
feat.parts|Textos e partes|Os textos e imagens que formam este elemento. Para mudar o que está escrito num botão, clique no texto aqui.|Texts and parts|The texts and pictures this element is made of. To change what a button says, click its text here.
feat.classes|Classes de estilo|Uma classe é uma aparência pronta com nome, como btn-danger (vermelho). Adicione ou tire classes para mudar a aparência de uma vez.|Style classes|A class is a ready look with a name, such as btn-danger (red). Add or take classes to change the look at once.
feat.shared|Estilos gerais|Muda a própria classe, e com ela TODOS os elementos que a usam. Para mudar só este, use as propriedades.|Shared styles|Changes the class itself, and with it EVERY element that uses it. To change only this one, use the properties.
feat.consts|Constantes do jogo|Valores com nome usados em muitos lugares, como a cor principal. Mudar um muda todos os que o usam.|Constants of the game|Named values used in many places, such as the main color. Changing one changes all that use it.
feat.act|O que faz|O que acontece quando alguém clica no botão, ou mexe no liga/desliga ou no controle deslizante. Não é preciso programar.|What it does|What happens when someone clicks the button, or moves the toggle or slider. No programming needed.
feat.where|De onde vem|O arquivo do jogo que desenha este elemento. Só informação; útil para quem faz mods.|Where it comes from|The game file that draws this element. Only information; useful to people who make mods.
feat.newPack|Novo pacote|Cria um arquivo vazio para guardar as suas mudanças e passa a salvar nele.|New package|Makes an empty file for your changes and starts saving in it.
feat.usePack|Editar este|As próximas mudanças passam a ser salvas neste pacote.|Edit this one|The next changes are saved in this package.
feat.onPack|Ligado|Desligar desfaz na hora tudo o que o pacote muda. O arquivo continua lá.|On|Switching it off takes back at once all that the package changes. The file stays.
feat.orderPack|Ordem|Se dois pacotes mudam a mesma coisa, vale o que está mais embaixo.|Order|If two packages change the same thing, the lower one counts.
feat.dropPack|Tirar uma edição|O X apaga só aquela mudança do pacote.|Take out an edit|The X deletes only that change from the package.
feat.export|Exportar XML e C#|Para quem programa: transforma o pacote em código pronto para um mod.|Export XML and C#|For programmers: turns the package into code ready for a mod.
feat.conflicts|Conflitos|Dois pacotes querem coisas diferentes do mesmo elemento. Vale o último da lista.|Conflicts|Two packages want different things of the same element. The last one in the list counts.
feat.problems|Problemas|Arquivos que não puderam ser lidos, ou edições recusadas por segurança.|Problems|Files that could not be read, or edits refused for safety.
feat.label|Texto|O que vai estar escrito no item novo. Você pode mudar depois.|Text|What the new item will say. You can change it later.
feat.more|Outros modelos|Peças prontas que esta tela do jogo já tem. Escolha uma para ver a descrição.|Other templates|Ready pieces this screen of the game already has. Pick one to see its description.
